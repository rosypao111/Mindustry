# 最终选定的G0固定玩家策略操作手册

G0是本项目的原版数值基线，不是未修改发行版二进制的同义词。G0、G1、G2、G3使用相同版本的引擎适配、对应策略的相同布局与相同动作优先级；分组改变指定倍率，不能为某组另换布局。

项目保留两套题目要求的策略：balanced和defensive，分别报告。二者在训练种子0完成过链A，之后冻结。能找到一个通关种子不表示所有正式种子都能通关；正式失败必须进入完成率分母。

## 从服务器启动到路线结束

1. 校验`frozen/S-v2/manifest.json`内的JAR、class、源码、参数、地图和布局哈希，启动一个独立JVM。地图种子固定0，战斗种子使用预注册值。实际调用原生`world.loadMap`、`logic.play`、`net.host`，并检查服务器已真正host。每个并发进程有独立端口与数据目录。
2. 按批准协议移除玩家预置Duo/Salvo且不退款，强制关闭作弊/无限资源；S生存胜利波30，A上限8，后续上限16，建造材料倍率规则为1。G0各评测倍率均为1。保留原生地图初始物资，后续按凭证实扣实入继承，保存`.initial.msav`。
3. 原生核心调用`requestSpawn`产生玩家单位。新写的Pilot控制这名真实玩家，不另刷建设单位；按冻结CSV读入订单。坐标为原生tile锚点，旋转为原生0–3值，config按原生方块配置处理。
4. 每步先执行原生待处理任务、模拟时钟、同步寻路，再执行自动玩家动作，然后推进原生物理和`Logic.update`；1步=1tick=1/60模拟秒。不是按“资源公式”直接改库存或判定战斗胜利。
5. 动作循环按以下优先级执行。缺钱、缺料、炮毁、缺弹等会改变完成时间，但不改变预注册订单坐标；不是承诺第几分钟免费造出某建筑。
6. 生存阶段以原生胜利/失守结束；攻坚阶段以首个敌核被毁结束，第二个敌核只记录。全部核心丢失优先，随后原生胜负、首核目标、5400秒时限。失败不进入下一阶段。成功时先从源库存扣出，目标按容量接收，记录溢出；上限按A→B与B→C分别执行。

## 每步实际动作优先级

- 先检查核心和玩家是否存活；玩家本体在射程内有敌人时使用原生瞄准、武器控制。生存第30波后若超过180秒仍有敌军，原有策略会用玩家追击残敌。
- 若是攻坚，先运行AttackSupport：集结、指挥及工厂/重构厂真实物流。出击检查每300tick一次，未达门槛时原生RTS集结于核心附近。
- 随后优先为核心附近燃烧发电机取真实煤并运输；从已付费煤钻获取，攻坚时可优先用核心煤。之后处理弹药。Scatter在有飞行威胁时优先级最高，其次Salvo，再次Duo；Scatter喂铅、Salvo在正式开启earlyGraphite配置下喂石墨、Duo喂铜。所需物资从核心或实际工厂取货；核心没有铜/铅则真实采矿。
- 冰雹有威胁且空弹时，原冻结Pilot可从真实石墨压缩机取货。非正式战役准备后来使用的额外补弹优先级修补，不会悄悄覆盖这份冻结S玩家。
- 物流处理后，先恢复被毁的重要已建订单（修复、电力、关键采矿/加工与防线）；再选择冻结CSV中第一个未完成订单。按已存在的原生建筑检查完成和配置，不能只把订单索引当实际完工数。
- 在完整剩余材料不足时，先卸下/存回玩家所携物品，再采铜/铅或向真实生产设施取所需材料；有料后才提交原生`BuildPlan`，由原生施工进度和扣料完成。不会调用`setBlock`替代付费落成。放置失败只记失败并保留该坐标，不根据处理组临时改位置。
- 矿石选择限于单位可采、可接近的实际露天矿格，按距离选择；移动以单位速度执行。核心装不下时寻找能接收的真实建筑；确实无接收处才调用原生丢弃，并记录`discard`，不把丢弃当成收入。

## 三阶段与攻坚差别

主链A：stainedMountains(A，300×300，核心48:67) → windsweptIslands(B，400×400，核心116:104) → fungalPass(C，150×250，核心66:22)。备选链B：A → fungalPass → overgrowth；相同A前缀可引用，不构成独立重复。

两套A布局都计划493项，但顺序不同；B各279项；Fungal各34项；Overgrowth各30项。下表给出实际计划数量，完整坐标和相对顺序见CSV。计划里的Lancer/硅厂等不等于每次运行都实际建成，报告必须用实际施工/产出验证覆盖。

balanced在攻坚按布局建陆军工厂/重构厂，启动前收集真实石墨360、硅450、铅200；工厂配置Dagger，并将硅/石墨送入重构厂得到Mace。集结至少8个白名单单位、实际总HP≥2000后，向最近的敌核发原生RTS攻击指令，可在首批波次前完成首核目标，属于有效零批次阶段。

defensive保留工厂最初东向出口，先由原生目标要求的3个Dagger触发`unitsBuilt`，再原生旋转工厂进入重构路径；至少8单位且HP≥2000、并达到原生wave≥2后才首次出击。不直接写入目标标志。其他地图没有该教程目标时，以实际存活Dagger数作为策略里已有的对应判断。

后续重构厂硅/石墨目标缓冲各80，工厂硅/铅各20；全部来自真实库存和生产。成军白名单为dagger/mace/fortress/nova/pulsar/quasar，排除玩家代理本体，损血单位按当前HP计。

C实时校准是单独的合法战役适配：必须实际支付研究与发射费，原生发射Shard可能使B/C每兵种上限只有8；不能将S的“不扣研究、协议继承、B的Foundation核心及cap16”冒充完整原生战役。首访Fungal的重构厂需占领本关，合法适配暂缓该订单并先造Dagger，保留2000HP门槛；8个150HP Dagger仅1200HP，可能无法按冻结策略出击。不得免费解锁、改HP/上限或新增核心升级策略来强行通关。实际到达/执行须由正式C日志验证。
