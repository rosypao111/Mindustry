# 正式实验实现约定（草案，尚未启动正式样本）

本文件补足自然语言题目中需由实现确定的记账细节。不是实验结果。正式冻结时须连同源码、布局、参数表和运行清单一起计算 SHA-256；冻结后不根据组间结果改策略。现有训练文件均不计入正式统计。

- 源码为 b873c01 + 已归档的评测补丁。S 使用原生 Logic、物理、寻路、生产、库存、施工、波次和网络服务器。固定 60 步/模拟秒；寻路与物理同步。施工音效节流也使用模拟毫秒，消除音调随机调用与机器速度的耦合。正式模式使用原生全局随机流仅在开局播种，不按步重置；按步随机子流仅保留为较早的诊断模式，不进入正式基准。所有运行适配须在报告中明确，并与 C 原生战役校准分开。
- 所有 S 地图生成种子固定为 0，战斗种子另设。训练使用 0–99；正式主实验使用 1000–1029，20 种子实验用 1000–1019。同一配置重复不增加样本量。相同前缀可缓存复用，但必须保存同源引用，不作为新增独立样本。
- 玩家预置 Duo/Salvo 在开局统一移除，不退款（用户已同意）；敌方不改。所有建造实际扣料。阶段携带实际从源核心扣除、目标核心按容量入账，凭证包含源余额及组别/种子。S 不扣研究资源；不手动跳过原生目标链，不手动抑制波次。
- α 是增量压力，原生难度取整之后，对非 boss 的正数施加 round(n*(1+α))；α=0 对应原生。boss 和零数保持原样。每组每出生点输出原生数、调整数、实际生成数。
- 批次在原生 spawnEnemies 调用开始时开立，同次同步生成完成时封口；以原生单位 ID 跟踪首次死亡或终止。输出未清批次的阶段终点删失。运行内 RMCT 采用各批次 min(清除时长, 阶段终点−生成时刻) 的算术平均，同时输出删失比例和仅完整清除运行的敏感性结果。不得用失守造成的短观察时间直接推断战斗变强。
- 5 分钟窗口为 [300k,300(k+1))。点事件按时刻入窗；速率按步区间重叠拆分。恰在阶段终点窗口边界的点事件另保留零时长边界窗，不计算其速率。窗口净短缺主实现使用期初核心可用库存，列名明确为 opening_core_stock；主答案“流量缺口”不依赖该库存选择。
- 实际供给来自原生钻头、加工厂和单位采矿的成功产出钩子。原生运输不重复计供给。建造需求采用实际扣料。加工与造兵满载需求按启用、配方已选、输出不堵塞/载荷及单位上限允许的生产门控计算，缺料/缺液/缺电不作为排除门控的条件。
- 炮塔空仓按题目统一记铜需求。对本身不接受铜的炮塔，换算倍率采用其原生可用弹药中物品 ID 最小者的 ammoMultiplier，记账物品仍为铜；这只是协议的虚拟满载需求，不能视作其实际可装填铜。非空按只读虚拟弹栈选择，模拟原生 hasAmmo 的选择顺序，不调用会换栈的接口。Salvo 每次模式 4 发逐发扣弹，Duo 1 发。威胁依据原生目标类型、敌对关系和射程判断，读取状态不重新选靶。
- 停机只在生产门控为真时累计缺料、缺液、缺电折损、零效率和效率损失；输出堵塞与睡眠另列。修复能量在原生建筑消费更新之后、执行生产之前，记录该次原生请求功率、供电满足率和时间尺度的实际积分，单位为游戏电能单位；有效治疗取原生 heal 前后实际 HP 差，材料取实际消费钩子。
- 代理订单在固定策略首次选择该任务时到期，未来尚未释放的任务不算逾期欠料。实际扣料冲减订单；被毁的未完工订单取消其余额并保留取消记录，新重建释放新订单。窗口输出到期未支付余额。
- 操作分类在开工时固定。原生带队伍的伤害调用上下文记录直接来源及连锁根来源；记录火焰起火、蔓延与火球传递的来源，覆盖跨步火灾。敌方直接或敌方触发的连锁摧毁留下原址重建标记。未知来源另列，不能一概算敌方。每名实际施工单位每步最多计 1/60 秒活跃执行时间；同一步多次施工若涉及多类，按施工调用次数分配，避免原生 buildCounter 累积导致重复计时。
- 静态齐射里程碑为连续 10800 步每步至少 3 座启用且有可发射弹药的 Salvo；实战里程碑在同一窗口内累计至少 5400 炮塔·步威胁交战。成军白名单 dagger/mace/fortress/nova/pulsar/quasar，要求实际在世界存活、非代理、至少 8 个且当前 HP 合计至少 2000。
- balanced 攻坚立即升级 mace；原生教程要求同时存在 3 个 dagger，该中间目标可能一直未满足。首波前攻下首核按题目有效，批次为 0，RMCT 和 η 必须为空。defensive 先在工厂东侧释放 3 个 dagger，原生 unitsBuilt 标志成立后转向北侧重构厂，首批波次发生后再反攻。任何一套都不写入该标志或手动设定波计时。
- 路线未达成里程碑用 3L 标注截断；真实配对差只用双方均达成的配对，截断差另列。完成率用 Wilson 95% 区间；报告种子数、到达数、删失数及技术无效数。所有缺少输入或最低样本不足的题目判为“证据不足”。
