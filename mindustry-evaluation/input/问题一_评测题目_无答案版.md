## 1. 题目描述

在 Mindustry 这类“工厂建设 + 塔防”游戏中，玩家面对同一套敌方波次压力时，有两条互斥的强化路线：

- **工业包 I**：提高采集、运输、加工环节的速率（**不直接增加任何战斗力**）；
- **攻防包 D**：提高炮塔弹药伤害，同时提高炮塔建造成本（**打得更强，但防线更贵**）。

核心问题是：**“靠建设解决战争”是否成立？**

即在固定的玩家策略与地图条件下，把资源投入工业链提速，是否比直接增强炮塔更能：

1. 缩短清敌时间；
2. 更早达成关键里程碑；
3. 降低“救火”负担（缺弹、停机、战损重建）；
4. 承受更大的波次压力。

### 1.1 回答形式的要求

在**同一玩家策略、同一布局、同一种子**下，对 G0 / G1 / G2 / G3 做**配对比较**，给出第 4 章五个问题的量化答案，并按第 7 章的预注册判据给出“成立 / 不成立 / 证据不足”的结论。

“唯一正确答案”的含义：在本文固定的协议版本下（参数、地图、布局、策略、时钟、指标定义均固定），**每次有效运行的日志只能算出一组数**；组间结论则是带样本量和置信区间的统计结果，不是单次均值。

## 2. 背景与实验设定

### 2.1 运行环境与通用约定

- 游戏本体为 Mindustry（本仓库源码，提交 `b873c01`）。所有参数改动**只作用于玩家队伍**，敌方同类单位与建筑不受影响（这一条需要单独验收）。
- 共享内容（研究价、施工工作量、敌方属性）不得被牵连改动。
- **主时钟为模拟时间**；自动化轨道使用固定步长，模拟时间与墙钟、机器速度无关，快进只改变墙钟速度。
- **确定性要求**：同一种子、同一配置的重复运行必须得到完全一致的日志（逐字节相同）。不一致的运行不得作为基准，须先定位分歧。
- **非作弊要求**：禁止刷物资与免费落成，所有建造由真实库存驱动；作弊类开关在载入时强制关闭。
- 采样必须是**只读**的：观察行为本身不得改变游戏过程。

### 2.2 三条轨道

| 轨道 | 用途 | 说明 |
|---|---|---|
| **S**（主统计） | 出全部主结论 | 自动化无界面快进、协议化继承 |
| **C**（校准） | 检验方向一致性 | 桌面客户端原生战役、实时、少量样本；用于校准研究与发射成本的影响，不做增兵扫描 |
| **G**（复现原题） | 复现原题地图设定 | 内置地图中没有 192×192 尺寸，只能使用星球生成区中尺寸为 192、无预设波次的区块；B、C 阶段沿用链A定义 |

### 2.3 阶段划分：前期 A / 中期 B / 后期 C

**链A（主链）**

| 阶段 | 地图 | 尺寸 | 模式 | 阶段完成条件 | 适用里程碑 |
|---|---|---|---|---|---|
| A 前期 | stainedMountains | 300×300 | 生存，胜利波次 30；核心为 core-shard，单位上限 8 | 玩家胜利的 GameOver（打完全部批次并到达第 30 波） | 齐射防线、26–30 波锁定 |
| B 中期 | windsweptIslands | 400×400 | 生存，胜利波次 30（来自预设）；核心为 core-foundation，单位上限 16 | 同上 | 齐射防线、26–30 波锁定 |
| C 后期 | fungalPass | 150×250 | 攻坚，存在敌方核心（图上共 2 个敌核） | **前沿敌方核心被毁**（被毁敌核数达到规定完成数 1） | 齐射防线、反攻部队成军、下达反攻、首个敌核 |

- 阶段 C 地图自带世界处理器，开局关闭波次计时；玩家建成陆军工厂并造出单位后，原生目标链才开启波次，这是原版战役行为。
- 纵深方向的第二个敌核**不作为完成条件**，其状态只做记录。

**链B（备选 / 稳健性检验）**：stainedMountains（生存）→ fungalPass（攻坚）→ overgrowth（攻坚）。两条链**分别报告，不合并**。

### 2.4 阶段终点与优先级

- **无敌核（生存图）**：阶段完成 = 玩家胜利的 GameOver。
- **有敌核（攻坚图）**：初始存在敌方核心，且被毁敌核数达到规定完成数；完成数为 0 时按原生判定（全部敌核被毁）。
- **同一步内的终点优先级**：玩家核心全部丢失 > 原生胜负（GameOver） > 修订目标达成 > 达到阶段时限 L。
- **阶段时限 L = 5400 模拟秒（90 分钟）**：它同时是运行上限和未达成里程碑的截断值。
- 原题的“≤60 分钟”降为**辅助判定**，单独列出，不进入完成率计算。
- 攻坚图若在首批波次生成前就完成，则该阶段批次数为 0，**属有效运行**，清敌统计为空。
- 波次口径说明：胜利波次设为 30 时，原生实际生成第 1–29 批，清场后到达第 30 波即获胜。
- 路线口径下未达成的里程碑，其时间按 3L 截断，并单独标注为截断值，不能与真实达成时间混算。

### 2.5 阶段间继承

- 阶段完成后，从本区核心**按携带上限实扣**，记为带出；下区核心按容量实入，记为带入。
- 原生基准路线的携带上限：
  - A→B：铜、铅各 1000；石墨、硅、钛各 500；金属玻璃 200。
  - B→C：铜、铅各 1500；石墨、硅、钛各 800；金属玻璃 300。
- 科技：原生基准路线**不设白名单**，地图规则允许的方块都可以建造，不扣研究资源。
- 研究与发射成本对结论的影响，由轨道 C 校准。

### 2.6 玩家策略与布局

- 使用**非作弊自动玩家**：禁止刷物资，建造由真实库存驱动。
- 使用**预注册的建造顺序 / 布局**：所有分组共用同一布局，组间差别只体现在“什么时候建得起来、会不会被打掉”，不得混入布局差异。
- 预注册两套布局策略：`balanced`（均衡扩产）与 `defensive`（先防后产），两套分别报告，不混合。
- 布局冻结后不得再改，否则前后结果不可比。

### 3.2 每个参数的含义与改值

| 参数 | 作用对象（仅玩家） | 原值 | 新值 | 理论效果（同条件下） |
|---|---|---|---|---|
| **M** | 机械钻头、气动钻头完成一次采矿所需的进度阈值 | 机械铜 650、煤 700 tick；气动钛 550 tick | 520、560、440 | 采矿进度速率 +25% |

| **G** | 石墨压缩机的生产周期 | 90 tick | 72 | 产出与耗煤 +25% |
| **S** | 硅冶炼厂的生产周期 | 40 tick | 32 | 产出、耗煤、耗沙 +25% |
| **P** | 硅冶炼厂的请求功率 | 0.5/tick（30/s） | 0.6/tick（36/s） | 单位产品耗电 ×1.2/1.25 = 0.96 |

**关于 M 的重要说明**：阈值缩短 20% 只是“同矿格、同效率条件下的理论值”。实际产量还会被矿格数量、预热、供水平方、出料堵塞改变，因此**实际效果必须以日志中的产出计量为准**，不能直接用理论值下结论。

**C 的使用前提**：建造成本倍率为 1；地图上无预置的玩家双管或齐射；禁止换队与遗迹接管；不跨组加载施工中的存档。

## 4. 评测目标：需要求出的目标答案

记号（仅用于说明）：分组 g、运行 r、阶段 s（A/B/C 对应前/中/后期）、阶段时限 L、运行数 N。

### 4.1 Q1：清敌时间、核心失守率、三区完成率、工业收益显现期

需要求出的量：

1. **批次清敌时间**：每一批次从生成到清场的时间。
   - 批次 = 一次实际波次调用。
   - 清除 = 该批次已封口且批次内单位全部首次死亡或终止。
   - 未清除的批次按删失处理（记到阶段结束为止），同时报告清除率。
2. **阶段平均清敌时间（RMCT，主指标）**：阶段内所有批次清敌时间的均值；先在运行内平均，再对运行等权平均，得到组均值。
3. **批次序号分层**：第 1–10 批为 early，第 11–20 批为 mid，第 21 批起为 late。注意原生生存图只生成 29 批，late 实际为第 21–29 批。
4. **核心失守率（两种口径都输出）**：
   - 到达条件口径：到达该阶段的运行中，因核心失守结束的比例。
   - 整条路线口径：全部运行中，最终因核心失守结束的比例。
5. **三区完成率**：A、B、C 三个阶段全部完成的运行比例，附 Wilson 95% 置信区间。技术无效运行不进分母，但单独报告。阶段 C 的完成指前沿敌核被毁。
6. **工业收益显现期 η**：各阶段上 G1 相对 G0 的阶段平均清敌时间缩短比例。
   - 预注册判据：前期 η ≤ 5%、中期 η > 10%、后期 η > 15% 时，判定“收益在中后期显现”。
   - 同时输出同种子配对下的时间差。
   - 若某阶段批次数为 0，则该阶段 RMCT 为空、η 记为不可计算，且**不得**输出“收益在中后期显现”的判定。

### 4.2 Q2：三个里程碑的提前或推迟

里程碑定义（每步末检查）：

| 里程碑 | 定义（自然语言） |
|---|---|
| ① 齐射防线（静态） | 在一段连续 180 秒的窗口内，已建成且启用的齐射炮不少于 3 座，且每一座都有可发射的弹药；达成时刻取该窗口末端 |
| ① 齐射防线（实战） | 在上述同一连续窗口内，“有弹且射程内存在威胁”的齐射·秒累计不少于 90 |
| ② 反攻部队成军 | 同一时刻，玩家兵种白名单内、存活、已加入世界、非核心单位、非代理化身的单位不少于 8 个，且生命总和不低于 2000；**仅攻坚阶段适用**（生存阶段没有反攻目标） |
| 下达反攻 | 攻坚阶段首次对敌方核心下达 RTS 攻击指令；它可能早于“成军”，因为出击阈值由策略设定 |
| ③ 有敌核 | 首个敌方核心被毁的时刻；以及敌核数从大于 0 变为 0 的时刻（后者仅在“全部敌核被毁”的设定下适用） |
| ③ 无敌核（26–30 波锁定） | 从第 26 批生成起、直到获胜为止，玩家建筑零损毁，且第 26–29 批全部清除 |

需要求出的量：

1. **路线口径的达成时刻**：整条路线上每个里程碑首次发生的累计模拟时间。未达成则按 3L 截断并标注。
2. **提前量**：同种子配对下，G0 与其他分组达成时刻之差的均值（分钟），正数表示提前。只有双方都达成的配对，其差值才是真实时间差；截断差单独标注。
3. **各组达成率**。

### 4.3 Q3：每 5 分钟窗口的供需缺口、缺弹、停机、修复与重建

对每个 5 分钟窗口、对铜 / 石墨 / 硅三种物品，需要求出的量：

1. **供给**：钻头与工厂的产出、单位采矿的产出之和。
2. **满载需求**（四项之和）：
   - 加工厂在生产门控为真时的满载物品需求；
   - 单位工厂造兵的物品需求；
   - 交战炮塔的弹药需求（按当前装填弹种计算，空仓按铜；齐射每次装填发 4 发、双管为 1，每发都扣弹）；
   - 建造的实际扣料。
3. **三个缺口口径（全部输出，主答案为流量缺口）**：
   - 流量缺口：需求超出供给的部分；
   - 净短缺：需求超出“供给 + 期初库存”的部分；
   - 到期未支付的建设需求（代理订单余额）。
4. **威胁期间缺弹**：射程内存在威胁、建筑已启用、但弹药不足以发射一次的“炮塔·秒”累计，同时输出分母（威胁秒）与比例。判定时只读状态，不得调用会改变弹药栈顺序或重新选靶的接口。
5. **工厂停机**（在“想生产”即生产门控为真的前提下）：缺料秒、缺液秒、缺电折损、零效率秒与效率损失；输出堵塞秒与睡眠秒另列，不计入缺料。
6. **战损重建消耗**：按物品分别列出实际扣料；并给出加权当量，权重为铜 0.5、铅 0.7、石墨 1、钛 1、硅 0.8。
7. **修复**：修复作用域下的有效治疗 HP 增量、修复设施获得的电能、修复物料的实际消耗。
8. **变化率**：同阶段同口径下，各分组相对 G0 的变化率。

### 4.4 Q4：扩产、布防、战损重建的操作时间比例

- 分类在开工处确定：
  - **rebuild（战损重建）**：该坐标曾被敌方摧毁、尚未在原址重建。
  - **defense（布防）**：炮塔、墙、单位工厂、重构厂、修复器、维修炮台。
  - **expand（扩产）**：其他，包括采矿、物流、电力、加工、液体。
- 需求出的量：三类各占建造执行时间的比例，以及**各自的绝对秒数**。
- 注意：比例下降可能只是因为其他类别变多，判断“是否减少救火”必须看绝对值。
- 真人轨道（可选）：墙钟活跃时间单独汇总，不与模拟时间相加；任务类别未标注时归入 other，不推测玩家意图。主观难度与挫败感只能通过问卷获得，不由日志推出。

### 4.5 Q5：增兵边界

- **增兵规则**：在原生难度取整之后施加放大系数 α；boss 组不放大；基准数量为 0 时保持 0。每组每个出生点都要输出基准数量、调整后数量与实际生成数量。
- **扫描范围**：α 从 0 到 2.0，步长 0.1（共 21 档），每档每组不少于 20 个配对种子。
- **需要求出的量**：每档的完成率与 Wilson 区间；**连续边界 α\***，即从 0 起所有已测档位完成率都不低于 90% 的最大 α。
  - α = 0 时就低于 90%，则边界为空。
  - 若最大测试档仍通过，只能报告“≥ 最大档”。
  - 另外报告“任一档通过的最大 α”。
- 说明：经验 90% 不等于总体概率不低于 90%。需要高置信声明时，应改用“置信区间下界不低于 90%”并增加样本量。

## 5. 分组、样本量与配对要求

| 实验 | 分组 | α | 每格种子数 |
|---|---|---|---:|
| 主实验 | G0–G3 | 0 | 30 |
| 分解 | G2H、G2C、G1X、G3X | 0 | 30 |
| 消融 | 11 组 | 0 | 30 |
| 增兵扫描 | G0–G3 | 0–2.0（21 档） | 20 |
| 轨道 C 校准 | G0–G3 | 0 | 5（实时） |
| 链B 稳健性 | G0–G3 | 0 | 20 |

- **配对**：同一个种子下运行 G0、G1、G2、G3，构成一个配对；样本量只来自不同种子。
- **确定性的样本含义**：同一种子、同一配置的重复运行结果相同，再跑不增加信息。
- **替补规则**：技术无效运行用同一种子重跑一次；仍然无效则记为缺失、单独报告，**不用新种子替换**。
- **样本量依据**：完成率在 90% 附近时，20 个样本的 Wilson 区间半宽约 ±13%。若要区分 85% 与 95%，应把边界附近的档位加到不少于 50 个样本。
- 未完成或未进入的阶段不计数；路线成功率用全分母。

## 6. 数据口径与有效性要求（预注册）

### 6.1 追踪与可追溯

1. 每条记录带运行号、严格递增的序号、阶段、步号与模拟时间；序号必须严格连续，否则整次运行判无效。
2. 运行清单须写入参数与倍率、种子、分组、版本；任一答案都能追溯到具体运行的具体事件行。
3. 核心库存逐事件对账：上一余额必须等于本条记录的起始值，差额等于变化量，否则判无效。
4. 每阶段开始保存快照，可复查或重放。
5. 采集异常、负库存、地图验收失败都会产生无效记录，该运行不进入统计，单独列出。
6. 高频原始事件（逐次伤害、逐次射击）默认只做窗口聚合；需要逐条审计时可开启原始事件输出。

### 6.2 窗口口径

- 5 分钟窗口按阶段相对时间划分。
- 区间量（速率类）按窗口与步区间的重叠长度精确切分；点事件归入包含其时刻的窗口。
- 阶段结束时写出最后一个不足 5 分钟的窗口，并标注实际时长。

### 6.3 无效与排除规则

| 情形 | 处理 |
|---|---|
| 缺少运行结束记录、序号断号、时钟回退、出现无效事件 | 运行无效 |
| 核心账对账失败、出现负库存 | 运行无效 |
| 地图尺寸、矿物、敌核模式验收失败 | 运行无效（该地图不适用于该链） |
| 运行中倍率或队伍改变、非固定步长（自动化轨道） | 运行无效 |
| 作弊规则被开启 | 强制关闭；检测到即无效 |
| 里程碑出现在不适用的阶段 | 运行无效（说明采集有错误） |
| 布局项无法放置 | 记为放置失败，运行仍有效；同一布局所有分组应一致，不一致须排查 |
| 阶段在首批波次生成前完成（批次数为 0） | 运行有效；该阶段清敌统计为空，η 不计算 |

## 7. 判定标准（预注册阈值，用于最后下结论）

1. **靠建设解决战争（G1 对 G2）**：G1 的路线里程碑（反攻部队成军、首个敌核、齐射防线实战口径）比 G2 至少提前 3 分钟，且 G1 完成率不低于 G2 减 5 个百分点 → 成立。若 G2 全面占优，而 G1 只是库存上升、里程碑不提前 → 判定为“工业转化链断裂”（需检查单位工厂产能、科技门槛、齐射建材门槛）。
2. **工业包开局惩罚**：若前期电网满足率低于 0.85，且 G1 失守率高于 G0 失守率 → 判定为“开局变难”。处方方向：让硅功率与产速匹配（单位产品耗电不变），或同步提高发电量。
3. **救火负担**：
   - 良性：G1/G3 相对 G0 的重建时间下降不少于 30%，且缺弹时间下降不少于 40%。
   - 恶性：G2 的重建当量与重建时间高于 G0；或 G1 的缺电、输出堵塞时间显著增加。
4. **协同**：若 G3 的增兵边界大于 G1 与 G2 各自边界的最大值 → 说明工业提速支撑了高成本强防线，存在组合平衡点。

任何输入缺失，或每组运行数低于最低要求，都应输出“证据不足”，不得强行下结论。

### 7.1 高级阶段无效时的三分诊断（防止误判）

当后期 G1 相对 G0 不显著时，按顺序排查：

1. **覆盖退出**：受工业包作用的设施，其产出占比明显下降。此时应比较 G1X 与 G1。
2. **瓶颈迁移**：钍、电力、单位上限、载荷、路径成为主导瓶颈。
3. **转化断裂**：覆盖充足、真实产出确有提升，但里程碑与战损没有改善，且两条链、两套策略都重复出现。

只有第 3 种情况才支持“当前设计下建设成果未转化为战力”这一**局部**结论；不能由此推出“工业建设整体无效”。

### 7.2 体验结论的边界

自动化轨道回答的是“发生了什么”：时间、资源、停机、战损、操作负担。玩家主观上是否觉得更难、更烦，需要真人轨道加问卷，二者分表报告，不能互相替代。
